## 隐私政策

最后更新日期：**2026年4月24日**

### 1. 我们收集的信息

当您访问本网站时，我们可能会通过以下方式收集信息：

- **Google Analytics**：匿名化的访问数据（页面浏览、停留时间、地理位置等），用于了解网站流量和改进内容
- **Google AdSense**：Cookie 和网站信标，用于展示相关广告（见下方说明）
- **Giscus 评论**：如果您使用评论功能，您的 GitHub 用户名和评论内容将被存储

### 2. Google AdSense

本网站使用 **Google AdSense** 展示广告。作为第三方供应商，Google 使用 Cookie 在本网站和其他网站上投放广告：

- Google 使用 DART Cookie 根据用户访问本网站和其他网站的记录来投放广告
- 用户可以通过 [Google 广告设置](https://adssettings.google.com) 停用 DART Cookie 的个性化广告
- 如需了解更多，请阅读 [Google 隐私政策](https://policies.google.com/privacy)

### 3. Cookie

本网站使用 Cookie 来：
- 记住您的主题偏好（浅色/深色模式）
- 分析网站流量（Google Analytics）
- 投放相关广告（Google AdSense）

您可以通过浏览器设置禁用 Cookie，但部分功能可能无法正常使用。

### 4. 第三方链接

本网站可能包含指向第三方网站的链接。我们对这些网站的隐私政策不承担责任。

### 5. 联系

如有隐私相关问题，请通过 GitHub 仓库 [openduran/duranblog](https://github.com/openduran/duranblog) 联系我们。
